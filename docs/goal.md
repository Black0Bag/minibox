# 项目目标

## 项目背景

minibox 是一个私有化强 Agent 系统：Go 后端作为中枢，Android APP 作为用户界面和设备侧能力代理。

## 总目标

提供可审计、可扩展、默认安全的 Agent 后端能力，并通过稳定的 REST、SSE、WebSocket 契约支撑 Android 前端开发。

## 成功标准

### 功能成功标准

- Agent、LLM 路由、知识库、工具权限、调度和设备代理具备可复现的后端验证证据。
- 前端可仅依赖已文档化的协议完成会话、流式事件、设备连接和管理界面开发。
- 危险设备操作、外部工具和升级能力保持明确审批边界。

### 质量成功标准

- `go test -count=1 ./...`、`go vet ./...` 和构建通过。
- 关键协议覆盖成功、失败、断线或重试场景。
- 配置、日志、测试报告和文档不泄漏凭据或用户数据。

## 范围边界（做 / 不做）

- 做：维护 Go 后端、协议契约、模拟设备测试、前端交接文档和稳定验证实例。
- 不做：前端不直接访问 SQLite；普通回归不执行真实 Android 副作用、自升级、主库恢复或外部平台写入。

## 约束条件

- 技术约束：Go 模块化单体、SQLite、REST/SSE/WebSocket、零 CGO 数据库驱动。
- 安全约束：本地凭据与源码、文档、日志隔离；设备写操作 fail-closed。
- 协作约束：后端协议变化必须同步更新前端交接文档。
